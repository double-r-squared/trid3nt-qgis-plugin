description=TRID3NT agent chat dock -- ask for geospatial data or a hazard simulation in plain language and the answer arrives as styled layers on the canvas.
about=Dockable chat panel that drives a TRID3NT agent over ws:// (this box or a tailnet peer). Every layer the agent publishes is STREAMED in place as a native QGIS layer -- COG rasters and FlatGeobuf vectors read ranged from the object store via GDAL /vsicurl/ (no project download); the one format that cannot stream (MDAL netCDF meshes) stages to a session-scoped temp dir cleaned up when the dock closes. Simulation gate card, drawn-rectangle AOI on every message, capped-jitter auto-reconnect with queued sends, and case switching (open any existing case's chat) that restores its layers in one gesture. The TRID3NT stack (agent, MinIO, Ollama) must be installed and running separately -- the plugin never starts or stops it.

changelog=0.3.17 - The declarative campaign's FORM and DRAW cards. A tool-payload-warning that carries a param_sheet now renders an editable PROPERTY GRID instead of a paragraph of provenance text: one row per declared param with its units, its declared range as the editor's placeholder, and a SOURCE BADGE saying where the value came from ("read from your prompt" / "derived by ..." / "labeled default"); the solver's own constants fold under "advanced". Every row is editable - editing a derived value is warned through its badge, never locked - and Submit IS the approval: the edits ride back on the existing tool-payload-confirmation (narrow_scope + revised_args), the server re-seats them through the declared bounds, re-derives whatever read them, and runs. Cancel declines and the run does not start. The spatial-input card gains multi-vertex DRAWING: a vector_draw request with purpose "aoi" or "line" now opens a vertex-capture tool (click per vertex, right-click to finish, Backspace to undo one, Escape to abandon) and replies with a role-tagged Polygon / LineString - so a workflow that asks for an outfall point, a study polygon or a section line can be answered on the canvas. The TAGGED barrier surface (per-segment wall / flap-gate) still degrades honestly to Cancel; the point and box picks are unchanged.
    0.3.16 - Feature cut: the Mode 2 offer-to-add catalog flow is removed (endpoint additions are hand-authored + discovery covers the same need). The offer-to-add card, its client envelope handling, and the sticky anonymous-user-id handshake hint all go -- every connection resolves to the one fixed local user server-side, so the client no longer replays an identity hint. Mesh staging fix: a native mesh now stages to the session temp dir under its SOURCE extension (.slf for a TELEMAC SELAFIN, .nc for a netCDF) instead of a hardcoded .nc -- MDAL selects its driver partly by extension, so a SELAFIN staged as .nc could be rejected; this is what loads the TELEMAC results-mesh animation (rain-on-grid / river-dye / coastal) through the dock.
    0.3.15 - Metadata repair: the 0.3.14 changelog block lost its continuation-line indentation, which QGIS parses as broken metadata (plugin flagged broken in the manager). Re-indented + a metadata parse test added to the suite.
    0.3.14 - Second native-numeric crash sweep (SIGBUS in qt_doubleToAscii / GenerateCountedDigits, arm64 non-finite-double-to-int32 saturation) -- NATE hit the SAME class of stack smash on 0.3.13 mid-session, so every styling family that hands a number to a native QGIS/Qt formatter was audited, not just the raster pseudocolor path the 0.3.8 fix covered. MESH (the gap): _clamp_mesh_scalar_classification now pins EVERY MDAL scalar dataset group's classification to a finite range via setClassificationMinimumMaximum, not merely the initially-active group -- switching the active scalar group from the styling panel, or the Temporal Controller scrubbing onto an all-dry/all-nodata timestep, previously handed that group's NaN/inf min/max straight to the native mesh colour-ramp legend. CANVAS: zoom_to_extent refuses a non-finite layer extent (a NaN bound defeats isEmpty(), every NaN comparison being False) before setExtent ingests it into the map-to-pixel transform. RAMP: explicit legend stops and categorical class anchors with a non-finite offset/value are dropped before reaching a native ColorRampItem; opacity is finiteness-checked before setOpacity (max/min pass NaN through). WS BOUNDARY (defense in depth): parse_layer_events sweeps every wire-borne numeric style field (opacity, legend vmin/vmax, per-class value/value_min/value_max) for NaN/inf at the message-parse choke point and drops them with one honest log line, so no future styling family can ferry a non-finite value to native code even if a call site forgets its own clamp. Vectors carry no computed class breaks (default rendering) and charts already reject non-finite points, so both are unaffected. Per-family degenerate-input tests added.
    0.3.13 - Charts window chrome shrunk (NATE first live look, QGIS 4 mac: "large header ... in the way"). The QDockWidget's native title bar is replaced with a slim 20px custom titlebar (small-font label + float/close buttons); the matplotlib NavigationToolbar2QT is swapped for a compact Home/Pan/Zoom/Save-only subset -- icon-only buttons at a fixed 16x16 size, coordinate readout off (the dock's own hover label already shows x/y). Figure chrome tightened (axes title pad 4, tight_layout pad 0.3). No data/series/label changes -- chrome sizing only; the dock-exact chart contract is unchanged.
    0.3.12 - Missing-matplotlib panel rebuilt around live-refuted assumptions: on QGIS 4 macOS, subprocesses launched from the QGIS Python Console do NOT inherit a working env (QGIS 4 configures its embedded interpreter in C++, PYTHONPATH stays unset) and, even fixed, that bundled Python has NO pip module at all ("No module named pip") -- there is no interpreter there to install into, by any method. The panel now shows ONE command for the platform actually running: Linux/Windows get a plain "pip install matplotlib" one-liner (system python3 on Linux, the OSGeo4W python.exe on Windows); macOS gets NATE's verified recipe instead -- download prebuilt wheels with the system python3 as a pure downloader (pip download --only-binary, --python-version/--platform derived at render time from this QGIS's own sys.version_info/platform.machine()) and unzip them straight into the QGIS profile's own python/ dir (derived from the plugin's own install path), which is already on QGIS's sys.path. install_dependencies.py mirrors the same split: it installs directly on Linux/Windows, and on macOS prints the wheel recipe instead of attempting pip. The QGIS Python Console snippet and the terminal PYTHONPATH+install_dependencies.py path are both removed -- both are dead ends on macOS.
    0.3.11 - In-dock install removed -- use install_dependencies.py. The Charts dock's Attempt-install button (QProcess against the exec_prefix-derived interpreter) failed to even start inside the QGIS app bundle on macOS; the guided panel now shows only the explanation, the exact terminal command (Copy button), and a restart-QGIS note -- run the command yourself in a real terminal.
    0.3.10 - General dependency installer: install_dependencies.py (pure stdlib, shipped in the plugin) checks every third-party dependency the plugin actually imports (currently just matplotlib -- QGIS 4.0.3 bundles numpy/pandas/shapely/pyproj/lxml/psycopg2, none of which we import), reports a present/missing table, pip-installs only what's missing into the running interpreter (--user fallback if the bundle site-packages is not writable), re-verifies, and exits nonzero if anything is still missing; --dry-run prints the table and command without installing. The Charts dock's Attempt-install button now runs this script via QProcess instead of raw pip -- one source of truth. The dependency list is pinned by a self-enforcing source sweep test (a new undeclared third-party import fails the suite).
    0.3.9 - Charts dock: QGIS 4 no longer bundles matplotlib (QGIS 3 did), so a missing install used to degrade to a bare error line. It now degrades to a guided fix panel: what's missing, why, the exact per-OS pip install command (derived from sys.exec_prefix/sys.executable at runtime, never hardcoded) with a Copy button, and an Attempt-install button that runs the bundled interpreter's pip via QProcess with streamed output -- success prompts an in-place reload, failure shows the honest stderr. Never installs without the click.
    0.3.8 - Fix a dock-open crash (SIGBUS in native Qt double-to-string) on QGIS 4 / Qt6 / macOS arm64: a non-finite (NaN/inf) or zero-span vmin/vmax from a restored layer's legend reached the color-ramp renderer, where the label precision computed to a non-finite value and, on arm64, saturated to INT_MAX. New render.formatting clamp seam (decimals bounded 0..12, ranges validated finite + increasing) guards every raster-styling site; chart series now drop NaN/inf points.
