  map              Generates a map from a RAS 2025+ result.

  prepare          Prepares a project or plan for compute. Ingests all external
                   data sources, computes property tables, and does any other
                   preprocessing steps necessary. Creates a single ready-to-run
                   (R2R) file that can be computed with 'ras solve'

  createterrain    Generates a RAS terrain from a collection of input rasters.

  mesh             Generates a mesh from an existing Geomtry file.

  clone            Clones a RAS file.

  info             Opens a file and dumps relevant information.

  hash             Hashes the given file with various hashing algorithms.

  solve            Run the RAS solver on different inputs.

  ui, gui          Launches the RAS GUI.

  healthcheck      Initializes and tests various RAS dependencies.

  explore          Interactive RAS project explorer with tree navigation.

  cleanup          Cleans up old backup and result files based on a configurable
                   retention policy.

  help             Display more information on a specific command.

  version          Display version information.
