2. What is being added: meshers/gmsh.py

One new registered mesher. The registry absorbs it with zero surface change - the tool signature, session, recipe, and gate are untouched. The composition splits responsibility by what each library is actually good at:

jobownerhow
coastal sizing intelligenceoceanmesh (kept)wavelength / bathymetric-gradient / feature sizing + gradation compute the edge-length grid, exactly as today
geometrygmsh OCC kernelshoreline polygons become the model; an obstacle is a boolean cut whose outline is EMBEDDED - its nodes are mesh topology, zero offset by construction, not by cleanup-pass luck
generationgmshtriangulates the model against the om2d sizing grid loaded as a background size field; fixed Mesh.RandomSeed, pinned version
editinggmshthe session retains the MODEL (geometry + fields); an edit mutates the model and re-meshes from it in-process - no container round trip, no input re-staging, sizing preserved
open-boundary segmentationoceanmesh (kept)identify_ocean_boundary_sections on the generated points/cells, as remediated
formatsshared writers (kept).msh native (official TELEMAC import) + the existing .slf/.cli/.gr3/fort.14/.2dm writers; one gr3 writer stands

2.3 Venue and state

gmsh ships as a self-contained manylinux wheel with no difficult native deps, so it installs into the SERVER env for true in-process edits (oceanmesh stays in the mesh image for sizing-grid computation; the sizing grid crosses once per session as an artifact). The session holds the gmsh model; realization is demand-pulled and batched per the session-economics ruling; realized meshes land in the prefix-keyed snapshot cache. The recipe stays the record - the model is reconstructible from spec + chain.

4. Out of spec

  • om2d generator retirement - decided only after the fidelity comparison; the om2d mesher stays registered untouched through the comparison period.
  • telapy adoption path - unchanged; supplied meshes and hand-edits keep the surgical route.
  • session-economics remediation - a sibling landing (already ruled), benefits every mesher, not gated on gmsh.
