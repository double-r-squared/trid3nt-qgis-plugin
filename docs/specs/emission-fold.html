1. The principle

The platform we run on (QGIS + GDAL + MDAL + MinIO) already does rendering, styling, temporal playback, and remote reads. We stop reimplementing all four. What remains OURS: which layers exist, their provenance, the presets, per-case durability, and the honesty record. Presentation NEVER appears in a workflow declaration - it does not change the simulation.

2. The paradigm: automatic emission, one presentation surface

behaviorrule
emissionAUTOMATIC - a produced layer appears (emit-on-fetch / emit-on-solve, kept). No .emit() exists anywhere.
presentationrestyle(...) is the ENTIRE surface - runtime, ad hoc, journaled: ramps, titles, presets, visibility. restyle(hide) is the un-emit.
user adjustmentsmade NATIVELY in QGIS on any layer; per-case durability persists them; a user choice always beats a preset.

3. Presets are native .qml - a UNIFORM MINIMAL FAMILY

Presets are keyed by DATA KIND, never by quantity: continuous raster ramp, classed/categorical vector, point-and-line reference, mesh contours/vectors - roughly FOUR. Everything quantity-specific (units, label, the one-scale range) is a PARAMETER of the uniform preset, never a new preset; the per-quantity preset zoo (the temperature_c-vs-stratified_flow class of finding) dissolves with it. Every emitted layer ships styled by its kind's default - restyling is predictable because every layer starts from one of four known bases. FETCHER STYLE LIVES IN THE FETCHER'S DECLARATION: source.yaml gains a style: row (kind + parameters) so emit-on-fetch styling is uniform, auditable, and diffable - never buried in Python mappings. This does not contradict presentation-free workflow declarations: a dataset describing its own default rendering is a fact about the DATA; workflow files still carry zero presentation. Sim outputs derive their default from the product contract's kind + quantity metadata.

styles.yaml and any yaml-to-qml compiler both die. The preset set is curated .qml documents - QGIS's own declarative style format - covering the FOUR renderer shapes products actually use: singleband pseudocolor (rasters), graduated + categorized (vectors), mesh contours/vectors (MDAL). The steering-file pattern applies verbatim: THEIR format, OUR writer (a small subset templater the restyle machinery drives - no human edits XML), THEIR validator STRENGTHENED per Stage 0: loadNamedStyle's boolean is well-formedness only - the gate asserts POST-LOAD STATE (renderer type as intended, ramp stops read back exactly, the render changed). One scale per quantity per packet remains law and now lives in the preset.

4. One store, one scheme (the transport)

Store hygiene per Stage 0: GDAL PAM is DISABLED in the plugin profile (a read must never mutate the store - the .aux.xml write-back class dies) and the vsicurl-era anonymous-download bucket policy retires (signed /vsis3 is the proven path, 403 control included). Products write ONCE into the EXISTING MinIO store - the staging and product stores unify into one bucket family. QGIS reads s3:// URIs NATIVELY via GDAL /vsis3 (endpoint + credentials configured once per profile, set by the plugin). Locally the endpoint is localhost; remotely it is the same URI at another address. The control plane (plugin -> daemon websocket) is already remote-capable; remote parity for the whole product is therefore an ENDPOINT SETTING, never a code path.

5. Temporal

Mesh results load as MDAL TEMPORAL layers; the wave stamps setReferenceTime from the run's own start (SELAFIN carries none - Stage 0 fact, else the scrubber reads 1900); the QGIS temporal controller is the canvas scrubber and playback (the UI pass inherits it free). The rasterize-frames-for-canvas machinery dies; GIFs survive ONLY where packets need them. The per-delivery double container-read (the memo seam) dies with it - display stops re-reading what products already read.

7. The model extension (the standing reminder)

The wave MODELS what it builds: docs/model/emission-seam.sysml - the emit record, the store contract (one bucket family, the id-to-URI interface), the preset/restyle surface, requirements (PresentationNeverInDeclarations, OneScalePerQuantity, UserChoiceBeatsPreset, EmissionIsAutomatic) with verify allocations; the planes index updates (the user plane's row gains its first modeled edge); views regenerate; seeded breaks prove the new rules fire. workflows/lib/ -> runtime/ rides as the mechanical rename with bindings moving same-commit.
