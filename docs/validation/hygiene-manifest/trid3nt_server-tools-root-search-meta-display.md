# Hygiene manifest: trid3nt_server/tools (root, search/, meta/, display/)

Scope: every tracked file at `trid3nt_server/tools/` top level plus the
`search/`, `meta/` and `display/` subtrees. `fetchers/` and `processing/` are
other agents' scopes. Every row below was written after opening the file end to
end; `__pycache__` is not tracked and carries no row.

Pure LOC is `scripts/loc_report.py`'s measure (total minus blank, comment and
docstring lines). YAML, JSON and Markdown never count as pure LOC and are
recorded as `-`.

Docstring limits applied: 3 physical lines for a function or class, 5 for a
module, the 1000-char front budget for an `@register_tool` body or a
`__doc__`-assigned string.
