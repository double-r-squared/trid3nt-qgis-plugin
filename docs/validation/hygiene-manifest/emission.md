# Hygiene manifest - `trid3nt_server/emission`

Read-only lens. Every tracked file in the scope was opened end to end by the
agent that wrote its row; the greps below the tables are sweep guards run after
the read, never the census. `__pycache__` is untracked and out of scope. The
package has no README, so there is no docs table here - see the note under the
sweep guards.

Pure LOC is `scripts/loc_report.py`'s measure with one correction: the
instrument subtracts blank lines and docstring lines independently, so a blank
line INSIDE a docstring is subtracted twice. The `pure LOC` column is the
corrected count; the parenthesised figure is what `loc_report` prints today.
Over this scope the defect understates pure code by 244 lines (3,736 corrected
against 3,492 reported), and it drives the docstring-only `__init__` negative
(`-2`).

NO file in this scope carries an LLM-facing docstring: there is no
`@register_tool` and no `__doc__` assignment anywhere in `emission/`, so the
1,000-char front budget governs nothing here and every docstring is an internal
one under the 3-line (function/class) / 5-line (module) limit.
