# Hygiene manifest - `trid3nt_server/workflows/telemac`

Read-only lens. Every tracked file in the scope was opened end to end by the
agent that wrote its row; the greps below the tables are sweep guards run after
the read, never the census. `__pycache__` is untracked and out of scope.

Pure LOC is `scripts/loc_report.py`'s measure with the same correction the mesh
manifest records: the instrument subtracts blank lines and docstring lines
independently, so a blank line INSIDE a docstring is subtracted twice. The
`pure LOC` column is the corrected count; the parenthesised figure is what
`loc_report` prints today. Over this scope the defect understates pure code by
487 lines (11,101 corrected against 10,614 reported) and drives six
docstring-only modules negative (`-1`).

The six `catalog/*.json` files are MACHINE-EXTRACTED data - the engine's own
dictionaries, never hand edited. They were read record by record rather than
line by line: every one of the 1,311 keyword records was parsed and its key set,
type, rubrique, default, file role and help text inspected, and the literal file
framing was read at head and tail. Their rows state what that read found.
