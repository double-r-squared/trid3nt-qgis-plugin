# Hygiene manifest - `contracts` (non-test)

Read-only lens. Every tracked file in the scope was opened end to end by the
agent that wrote its row; the marker census and greps below the tables are sweep
guards run AFTER the read, never the census. Scope is `git ls-files contracts`
minus `contracts/tests/**`: 24 Python modules, the `py.typed` marker, the
package README and `pyproject.toml`, and the 45 generated JSON Schemas. Nothing
under `contracts` is untracked.

Pure LOC is `scripts/loc_report.py`'s measure with the same correction the
`emission` manifest records: the instrument subtracts blank, comment and
docstring lines independently, so a blank line INSIDE a docstring is subtracted
twice. The `pure LOC` column is the corrected count; the parenthesised figure is
what `loc_report` prints today. Over this scope the defect understates pure code
by 403 lines (2,988 corrected against 2,585 reported).

NO file in this scope carries an LLM-facing docstring: there is no
`@register_tool` and no `__doc__` assignment anywhere under
`contracts/trid3nt_contracts/`, so the 1,000-char front budget governs nothing
here and every one of the 219 docstrings is an internal one under the 3-line
(function/class) / 5-line (module) limit. The one place an LLM-facing docstring
touches this scope is as DATA: `SourceSpec.docstring` is the field a
`source.yaml` carries a promoted tool's docstring in, and it is out of the
limit's reach because it is a value, not a docstring.

THE SCOPE'S HEADLINE: 219 docstrings hold 3,328 physical lines against 2,988
lines of pure code - this scope documents itself at 1.11 lines of docstring per
line of code, and 148 of the 219 (68%) are over the limit. 74 comment blocks
exceed 6 lines. The marker census counts 454 history / spec-notation /
attribution markers across the 24 modules.

THE CROSS-CUTTING CONSEQUENCE, stated once here rather than in 45 rows: every
`contracts/schemas/*.json` `description` string is a VERBATIM mirror of the
docstring above it, and `contracts/tests/test_schema_drift.py` fails the moment
the two diverge. Trimming a single docstring in this scope therefore REQUIRES
regenerating the schema directory in the same commit
(`./venvs/agent/bin/python -m trid3nt_contracts.export_schemas`, the exact
string `export_schemas.REGEN_COMMAND` pins and the drift gate quotes). The 45
schema rows below carry no independent fate for that reason.

EVIDENCE THAT A GREP CANNOT FINISH THIS: a previous mechanical strip of spec
notation deleted the reference tokens and left the surrounding sentences
broken. Fifteen mangled fragments survive, and because the schemas mirror the
docstrings, several are committed into the generated JSON as well:
