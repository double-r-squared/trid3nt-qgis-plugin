# Hygiene manifest: trid3nt_server/workflows/{runtime, solver, shared} + the workflows package root

wrote its row. Pure LOC is `scripts/loc_report.py`'s measure (no blank, comment or
docstring lines). Docstring limits applied: 3 physical lines for functions and
classes, 5 for modules; LLM-facing `@register_tool` bodies keep the 1000-char
pre-`Returns:` front budget instead. Comment blocks are uncapped; they are listed
only to say whether each is a constraint at its point of use or narration.

Disallowed-class abbreviations used in the docstring column:
`hist` history, `spec` spec notation (Invariant N, A.6/A.7, section marks,
build-contract, kickoff, phase/milestone/wave labels), `attr` person attribution,
`why` rationale essay, `arch` architecture and neighbour references, `narr` usage
narrative, `ex` examples, `roll` per-field roll-call of a typed model.

## Cross-cutting findings

1. **The four LLM-facing docstrings in scope all bust the 1000-char front budget**:
   `rerun_workflow` 1803, `run_solver` 1434, `wait_for_completion` 1163,
   `read_run_diagnostics` 1188. Every one is a hand-written docstring rather than a
   `render_docstring` product, so nothing enforces the budget on them today
   (`render_docstring` raises at 1000 for the templates it renders).
2. **Docstring lines exceed pure LOC in five files**: `layer_fields.py` (9 vs 10),
   `publish_product_layer.py` (24 vs 19), `rerun_workflow.py` (54 vs 14),
   `resolution.py` (57 vs 56), `accepts.py` (27 vs 32 - near parity).
3. **Dead-engine residue is concentrated in four files** - `solver/solver.py`,
   `shared/cog_io.py`, `shared/register_published_manifest.py`,
   `shared/solve_progress.py` - all four describing SFINCS / SWMM / MODFLOW /
   GeoClaw / Landlab / OpenQuake paths that no longer exist in the tree. These are
   documentation fixes here, but each also exposes code with no remaining caller
   (`_read_crs_from_dataset`, `NODATA_DEPTH_M`, `SOLVER_BACKEND_LOCAL_DOCKER`,
   `_LIVE_SOLVE_PROGRESS_INTERVAL_S`) and one dead branch
   (`reuse.py`'s `node.kind == "when"`), which belong on the deletion ledger for
   the wave that owns the module - not to this wave.
4. **Non-ASCII characters survive in four files** (`solver.py` 38 lines,
   `solve_progress.py` 3, `outputs_manifest_io.py` 2, `cog_io.py` 1), two of which
   sit under a `_common.py` sibling that asserts "ASCII only. No emojis, no
   typographic dashes."
5. **EXEMPT candidates**, in order of strength: `resolver.reseat_revised`,
   `resolver.rederive_revised`, `shared/aoi.acquire_aoi`,
   `runtime/errors.LeakScanTruncated`. Four is already close to the ~10 ceiling the
   ruling sets across the whole repo, so the scope should probably surface at most
   the first two.
