# Hygiene manifest: trid3nt_server/server + main + persistence + plugin_repo + package root

Read-only census. Every file in the scope was opened end to end by the agent that
wrote its row. Pure LOC is `scripts/loc_report.py`'s measure (no blank, comment or
docstring lines). Docstring limits applied: 3 physical lines for functions and
classes, 5 for modules; LLM-facing `@register_tool` bodies keep the 1000-char
pre-`Returns:` front budget instead (this scope registers no tools, so the count
limit governs everywhere). Comment blocks are uncapped; they are listed only to
say whether each is a constraint at its point of use or narration.

Disallowed-class abbreviations used in the docstring column:
`hist` history, `spec` spec notation (Invariant N, A.6/A.7/H.3/D.6, F<n>, JOB/job
labels, OPEN-<n>, Stage N, FIX A/B, Part A/B, task-<n>, ADR <n>, wave labels,
`#<n>` job numbers, v0.1/M1/M7), `attr` person attribution, `mem` memory
filenames (`feedback_*`), `why` rationale essay, `arch` architecture and
neighbour references, `narr` usage narrative, `ex` examples, `roll` per-field
roll-call of a typed model.

`_core` below is a MODULE THAT NO LONGER EXISTS. It was the pre-split monolith;
nine files in this scope still document their own contents as "extracted from
`_core`", say which names "stay in `_core`", and name `_core` as the module that
re-imports them. Nothing imports it and nothing can.
