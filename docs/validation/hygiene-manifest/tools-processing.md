# Hygiene manifest - `trid3nt_server/tools/processing`

Read-only lens. Every tracked file in the scope was opened end to end by the
agent that wrote its row; the greps below the tables are sweep guards run after
the read, never the census. `__pycache__` is untracked and out of scope.

Pure LOC is `scripts/loc_report.py`'s measure with one correction: the
instrument subtracts blank lines and docstring lines independently, so a blank
line INSIDE a docstring is subtracted twice. The `pure LOC` column is the
corrected count; the parenthesised number is what `loc_report` prints today.
Over this scope the defect understates pure code by 687 lines (11,697 corrected
against 11,010 reported) and drives one docstring-only module negative (`-1`).

Scope totals: 73 Python files (11,697 pure LOC, 20,139 raw, 4,595 docstring
lines, 1,490 comment lines) + 34 `corpus.yaml` retrieval files.
426 docstrings, **258 over the limit** (functions/classes > 3 physical lines,
modules > 5). Nine full-line comment blocks exceed 6 lines.
