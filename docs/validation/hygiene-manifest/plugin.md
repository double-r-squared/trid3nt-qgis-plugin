# Hygiene manifest - `plugin/` (non-test)

Read-only lens. Every tracked file in the scope was opened end to end by the
agent that wrote its row; the greps below the tables are sweep guards run after
the read, never the census. `plugin/tests/` is out of scope (it is the TESTS
stage's); `__pycache__` is untracked. The two PNGs are binary assets: their
identity (format, dimensions, byte size) was read, not their pixels.

Pure LOC is `scripts/loc_report.py`'s measure with one correction: the
instrument subtracts blank lines and docstring lines independently, so a blank
line INSIDE a docstring is subtracted twice. The `pure LOC` column is the
corrected count; the parenthesised figure is what `loc_report` prints today.
Over this scope the defect understates pure code by 239 lines (8,950 corrected
against 8,711 reported).

NO file in this scope carries an LLM-facing docstring: there is no
`@register_tool` decorator and no `__doc__` assignment anywhere under
`plugin/`, so the 1,000-char front budget governs nothing here and every
docstring is an internal one under the 3-line (function/class) / 5-line
(module) limit.
