# Hygiene manifest - `trid3nt_server/{gates,cases,sandbox,testing}`

Read-only lens. Every tracked file in the scope was opened end to end by the
agent that wrote its row; the sweep guards below the tables were run AFTER the
read, never as the census. `__pycache__` is untracked and out of scope; the
scope holds 32 tracked files and no untracked ones.

Pure LOC is `scripts/loc_report.py`'s measure with one correction: the
instrument subtracts blank lines and docstring lines independently, so a blank
line INSIDE a docstring is subtracted twice. The `pure LOC` column gives the
corrected count with `loc_report`'s own figure in parentheses. Over this scope
the defect understates pure code by 276 lines (5,077 corrected against 4,801
reported). Scope totals: 5,077 pure LOC, 2,077 docstring lines.

Limits applied: 3 physical lines for a function or class docstring, 5 for a
module docstring. Comment blocks are UNCAPPED; the `> 6 lines` column records
them so each can be read as a constraint at its point of use or as narration.
