# Hygiene manifest - `trid3nt_server/adapters` + `credentials` + `fallbacks`

Read-only lens. Every tracked file in the scope was opened end to end by the
agent that wrote its row; the greps below the tables are sweep guards run after
the read, never the census. `__pycache__` is untracked and out of scope. The
scope holds no README, no doc page and no decision record, so only the code
table applies.

Pure LOC is `scripts/loc_report.py`'s measure with one correction: the
instrument subtracts blank lines and docstring lines independently, so a blank
line INSIDE a docstring is subtracted twice. The `pure LOC` column gives the
corrected count with `loc_report`'s own figure in parentheses. Over this scope
the defect understates pure code by 223 lines (4,026 corrected against 3,803
reported).

A second measurement caveat is specific to this scope: `adapter.py` carries
`SYSTEM_PROMPT`, a 511-line LLM-facing prompt literal (lines 366-876). It is an
assignment, not a docstring, so `loc_report` counts every line of it as pure
code. `adapter.py`'s real executable body is about 1,074 lines, not 1,585, and
the file's LOC should never be read as complexity without that subtraction.
