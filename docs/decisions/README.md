# Design decisions

One short note per decision that shapes this repo: a few lines of context, the
decision, the consequence. Add a new numbered file when a decision lands.

**A record is BINDING or it is DELETED.** There is no superseded state that
keeps a file. When a later ruling replaces a record, the record goes and git is
the archive; when a later ruling contradicts a record that still binds, the
record is AMENDED IN PLACE so it says what is true. A live constraint inside a
record being deleted is lifted into the record that succeeds it first, so no
constraint dies with its file. The index below is regenerated from the folder,
so a record that is not listed here does not exist.
