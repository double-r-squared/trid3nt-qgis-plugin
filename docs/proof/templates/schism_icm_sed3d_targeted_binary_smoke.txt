--- Recipe CORRECTIONS discovered in execution (ADR 0249->0250 precedent) --------
* Erate must be a Fortran double literal (1.600000d-03), not %e+d0 ("1.6e-03d0"
  = "Bad data for namelist object erate").
* Scribed I/O: nscribe MUST be >= the number of scribed output variables
  (elev+T+S+iof_sed/iof_icm), else "INIT: Too few scribes". The entrypoint default
  (nscribe=2) is too low for a module deck -- a landed template must size nscribe.
* ICM iRad=0 hard-requires ihconsv=1 + nws=2 (sflux). iRad=1 + a tiny
  ICM_rad.th.nc is the cheap radiation source that keeps the deck sflux-free.
* Suspension is SOURCE-DRIVEN on the idealized channel: the tidal+river bottom
  stress is sub-critical, so bed erosion yields ~0; injecting river SSC (msource)
  makes the settling discriminator (fine vs coarse) the physics on show.
* bctides.in needs ONE extra per-module tracer-type flag (0 = no boundary input)
  appended to the open-boundary flag line for the compiled SED/ICM module.
