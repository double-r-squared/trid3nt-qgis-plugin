OceanMesh2D standalone coastal meshes (ADR 0192 sandbox)
=========================================================

These are shoreline-following, gradation-limited triangular meshes generated by
the authentic CHLNDDEV oceanmesh (OceanMesh2D Python port) for four US coastal
AOIs. Each was built from real GSHHG shoreline + real NOAA/USGS topobathy
(ETOPO 2022 base + CUDEM 1/9" + 3DEP). Two OceanMesh2D sizing functions are
active: feature_sizing (distance-to-shore / medial-axis) and wavelength_sizing
(shallow-water wavelength from bathymetry), gradation-limited (g=0.2); land
(exterior) faces are deleted.

Files per AOI (<aoi> = delaware_bay | duck_nc | tampa_bay | puget_sound):
  <aoi>.2dm          SMS 2dm mesh, node Z = topobathy elevation (positive-up).
                     MDAL-native -- opens directly in QGIS.
  <aoi>.slf          SELAFIN / SERAFIN geometry (TELEMAC-2D), single variable
                     BOTTOM = elevation. MDAL-readable AND TELEMAC-loadable.
  <aoi>_hgrid.gr3    SCHISM hgrid.gr3, node depth positive-down.
  <aoi>.fort.14      ADCIRC/SWAN(unstructured) grid, depth positive-down (bonus).

Load in QGIS (either file type):
  Layer > Add Layer > Add Mesh Layer... > select <aoi>.2dm  (or <aoi>.slf)
  The mesh renders immediately; the dataset group (Z / BOTTOM) carries the
  bathymetry -- style it via the layer's Symbology > Contours/Datasets.

TELEMAC use: <aoi>.slf IS a valid TELEMAC-2D geometry file (proved by reading it
back with the openTELEMAC data_manip SERAFIN reader). Point a TELEMAC steering
file GEOMETRY FILE at it, or open in BlueKenue.

All coordinates are EPSG:4326 (lon/lat degrees).
Regenerate: scripts/sandbox/oceanmesh/build_coastal_mesh.py
