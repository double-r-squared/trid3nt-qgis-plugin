about=Dockable chat panel that drives a TRID3NT agent over ws:// (this box or a tailnet peer). Every layer the agent publishes is materialized as a native QGIS layer: rasters as XYZ tile layers (TiTiler templates), vectors from inline GeoJSON or the MinIO object store. Simulation gate card, drawn-rectangle AOI on every message, capped-jitter auto-reconnect with queued sends, and case switching (open any existing case's chat) that restores its layers in one gesture. The TRID3NT stack (agent, MinIO, TiTiler, Ollama) must be installed and running separately -- the plugin never starts or stops it.
