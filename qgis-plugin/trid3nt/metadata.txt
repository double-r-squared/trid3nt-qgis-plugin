about=Dockable chat panel that drives a TRID3NT agent over ws:// (this box or a tailnet peer). Every layer the agent publishes is STREAMED in place as a native QGIS layer -- COG rasters and FlatGeobuf vectors read ranged from the object store via GDAL /vsicurl/ (no project download); the one format that cannot stream (MDAL netCDF meshes) stages to a session-scoped temp dir cleaned up when the dock closes. Simulation gate card, drawn-rectangle AOI on every message, capped-jitter auto-reconnect with queued sends, and case switching (open any existing case's chat) that restores its layers in one gesture. The TRID3NT stack (agent, MinIO, Ollama) must be installed and running separately -- the plugin never starts or stops it.

changelog=0.3.10 - General dependency installer: install_dependencies.py (pure stdlib, shipped in the plugin) checks every third-party dependency the plugin actually imports (currently just matplotlib -- QGIS 4.0.3 bundles numpy/pandas/shapely/pyproj/lxml/psycopg2, none of which we import), reports a present/missing table, pip-installs only what's missing into the running interpreter (--user fallback if the bundle site-packages is not writable), re-verifies, and exits nonzero if anything is still missing; --dry-run prints the table and command without installing. The Charts dock's Attempt-install button now runs this script via QProcess instead of raw pip -- one source of truth. The dependency list is pinned by a self-enforcing source sweep test (a new undeclared third-party import fails the suite).
0.3.9 - Charts dock: QGIS 4 no longer bundles matplotlib (QGIS 3 did), so a missing install used to degrade to a bare error line. It now degrades to a guided fix panel: what's missing, why, the exact per-OS pip install command (derived from sys.exec_prefix/sys.executable at runtime, never hardcoded) with a Copy button, and an Attempt-install button that runs the bundled interpreter's pip via QProcess with streamed output -- success prompts an in-place reload, failure shows the honest stderr. Never installs without the click.
0.3.8 - Fix a dock-open crash (SIGBUS in native Qt double-to-string) on QGIS 4 / Qt6 / macOS arm64: a non-finite (NaN/inf) or zero-span vmin/vmax from a restored layer's legend reached the color-ramp renderer, where the label precision computed to a non-finite value and, on arm64, saturated to INT_MAX. New render.formatting clamp seam (decimals bounded 0..12, ranges validated finite + increasing) guards every raster-styling site; chart series now drop NaN/inf points.
